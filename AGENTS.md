# Project instructions

Keep all project skills and their supporting files under `.agents/skills/` in this repository so the whole team shares the same version. Put new or imported skills there and reference them with repo-relative paths. Never add, install, or update project skills in the Codex app, its global skills directory, or any personal skills directory.

For any product listing or listing-image work, read and follow [the product listing design skill](.agents/skills/product-listing-design/SKILL.md). Respect the user's requested scope and any chat-only instructions.

For listing-image work, inspect each specified reference image and map its content hierarchy and layout before creating a card-by-card brief. Generate and inspect one standalone sample before generating the rest, then review every image individually against the brief and the skill. Correct failures before delivery. Follow the user's explicit directions for branding, imagery, sequence and output format.

## Meta Ads

Use the [Meta Ads skill](.agents/skills/meta-ads/SKILL.md) for campaign work. Read the [strategy playbook](docs/meta-ads/strategy.md) for planning. Follow the team's [brand rules](docs/meta-ads/brand-rules.md) and use the saved campaign plan for account settings and campaign targets. Use read-only Meta access for agent work and give the authorized operator the preview for any account change.

Start every agent-created campaign, ad set, ad, and saved audience name with `agi-`. Use only Meta campaigns, ad sets, ads, and saved audiences with that prefix for account research and optimization.
