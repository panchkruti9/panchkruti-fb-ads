# Find the creative question the evidence can answer

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Compare fairly

Compare concepts with their actual spend, dates, audience mix, placements and post-edit age. Unequal delivery inside an ad set is not a randomized A/B test. A low-spend ad is underexposed, not automatically a loser.

## Find the bottleneck

Strong opening response but weak arrivals points first to click quality, loading or measurement. Arrivals without intent can suggest message/offer mismatch. Checkout loss calls for store checks. Rising frequency and weakening comparable results can support a fatigue hypothesis, not a universal frequency cutoff.

## Choose the next idea

Preserve a working buying reason when only execution is weak; test a new angle when evidence challenges the reason to buy. Change a meaningful variable and write the expected observation.

## Handoff

Name the exact ad and concept, evidence, uncertainty and next creative brief. Keep the previous result in history so the next cycle does not unknowingly repeat the failed approach.
