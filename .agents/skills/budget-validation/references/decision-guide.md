# Check the proposed increase against live exposure

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Read fresh funding

Use the GitHub Meta gateway to verify current account commitments, spend to date, budget ownership and currency. Cached research alone is insufficient for a spending decision.

## Avoid double counting

Campaign-budget campaigns contribute their campaign allocation; ad-set-budget campaigns contribute applicable ad-set funding. Count all active account exposure. Verify the target still has the assumed current budget before substituting the proposal.

## Compare limits

Check projected daily/monthly exposure against the saved policy and any narrower request. Separate a forecast from verified provider spend controls. An allocation is not a promise of exact daily pacing.

## Handoff

Return actual amounts, the exact proposed change and pass/fail reasons. When headroom changed, revise the proposal rather than silently reducing a different campaign or asking for a generic approval.
