# Activation checkpoint

This is the Campaign Launch skill checkpoint after Campaign Build. The worker reads the saved build receipt, storefront and available Meta placement previews. It collects current account pixel ownership, Purchase optimization and event activity, installed storefront integration, assigned variant checkout navigation and account spending control before asking the user for evidence. Record source, product/variant, pixel, timestamp and verification scope. Existing store-wide Purchase events are not proof of an exact-product order or event deduplication. A new paid test order is not a universal prerequisite. Keep any genuine remaining limitation explicit.

The preview API confirms a preview can be generated. The agent/operator inspects the actual previews for the exact ad IDs and checks crop, text, URL and CTA. Record that inspection. Standing management authority covers a launch within its allocation using approved creative; legacy runs follow their saved owner approval rules. The executor checks signed objects, creative fingerprints, destination, budget and appropriate spending control immediately before applying it. For a new campaign it activates children first and parent last. Report configured status and effective delivery separately. A verified activation schedules monitoring; actual delivery determines exposure.

If media, landing page, settings, scope or spend controls change, resolve the affected evidence before execution. If an activation partially succeeds, reconcile the journal and retain the original proposal until the exact outcome is understood.


An exhausted account limit becomes an explicit proposed account-wide change rather than another technical setup question. The proposal caps the additional allowance by the saved monthly headroom and the planned review window. Meta reads `spend_cap` in minor currency units but accepts updates in major currency units. The executor journals and reads back the exact approved limit before activation, and can reconcile an ambiguous limit update. No limit change occurs during preparation.
