# Apply one exact authorized improvement

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Scope the change

Match the decision to the enrolled managed campaign and supported operation. Prepare the exact target, expected effect and current budget impact. Preserve approvals already recorded for that proposal.

## Execute and verify

Use the GitHub Meta job for the approved mutation. Read the exact target afterward and record before/after settings, status and any partial outcome. Reconcile uncertain delivery before retrying.

## Restart comparability

A material change starts a new clean reporting window. Save its time, preserve the old strategy/results and wait for the recorded lag when judging purchases.

## Report

Tell the user what actually changed and the next check time. If the recipe cannot perform the desired change, explain the supported preparation already done and the specific remaining capability; do not claim it was executed.
