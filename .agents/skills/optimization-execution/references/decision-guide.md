# Apply one exact authorized improvement

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Scope the change

Match the decision to the enrolled managed campaign and supported operation. Prepare the exact target, expected effect and current budget impact. Preserve approvals already recorded for that proposal.

## Execute and verify

Use the GitHub Meta job for the approved mutation. Read the exact target afterward and record before/after settings, status and any partial outcome. Reconcile uncertain delivery before retrying.

## Restart comparability

A material change starts a new clean reporting window. Save its time, preserve the old strategy/results and wait for the recorded lag when judging purchases.

## Report

Tell the user what actually changed and the next check time. If the recipe cannot perform the desired change, explain the supported preparation already done and the specific remaining capability; do not claim it was executed.

Read the shared [operating knowledge](../../meta-ads/references/operating-knowledge.md) for source references and evidence limits. The current skill's output schema remains authoritative.

## Applied purchase decisions

Match the chosen operation to exact managed scope and saved authority. Under standing allocation, complete routine operator signing without sending the user another launch question. Generated-media approval and higher total spend remain separate concrete owner decisions. Prepare the operation before asking for a decision.

For allocation verify starting amounts, reduce first, read back, then increase the receiving budget. A timeout is reconciled using the existing journal; do not restart the transfer. For website audience creation record the returned ID and later delivery eligibility before targeting. Record changed object IDs and compare affected periods without wiping unaffected creative history. A verified receipt, not a local proposal, establishes completion.

Read the [shared decision method](../../meta-ads/references/decision-method.md) for calculations, evidence grades, scenario diagnosis, authority and maintained source links. Preserve a dated observation versus hypothesis distinction in the handoff.
