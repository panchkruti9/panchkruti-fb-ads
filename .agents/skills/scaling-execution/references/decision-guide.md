# Increase spend and measure the new level

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Before execution

Verify the signed approval, current target budget, saved campaign configuration and live account headroom. If a human or another process edited the target, return to a current proposal rather than applying an old assumption.

## Execute exactly

Use the GitHub Meta job and journal the mutation before dispatch. Read back the new amount and account exposure. A timeout requires reconciliation, not another increment.

## After execution

Record the material-change time and first complete new window. Preserve the prior results and assess whether the higher allocation maintained contribution, delivery and fulfillment quality.

## Report

State the verified amount, effective state and next check. If the result is partial or unverified, say that precisely and retain the recovery task until resolved.
