# Match message to purchase readiness

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Map the journey

TOFU introduces a relevant buying situation; MOFU explains use, differences and objections; BOFU resolves the final purchase question with the verified offer and destination. Decide which question matters for this product now.

## Match delivery

A cold prospect can see an objection-led ad, and a broad Sales campaign can contain multiple message stages. A distinct retargeting group needs an available, relevant audience and enough exposure; a folder name is not an audience.

## Choose exclusions

Use verified recent purchasers when the campaign is acquiring new buyers and the exclusion matches the product goal. For replenishment or cross-sell, explain the appropriate recency and offer. Avoid removing so many people that useful delivery becomes impossible.

## File the creative

Carry each concept's funnel stage into ad naming and Drive filing. Save new originals under the configured stage/product folder with revisions. Reuse approved files in place and record the exact file used.
