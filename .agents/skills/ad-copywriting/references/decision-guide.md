# Write a clear path from interest to purchase

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Compose the message

Open with a relevant situation or product benefit, explain the offer, give credible support, resolve the main objection and use a fitting action. Match the destination and the selected funnel question.

## Use the right evidence

Use product-page or packaging wording for ordinary benefits at the same qualification level. Do not invent testimonials, guarantees, urgency, discounts or clinical certainty. Do not imply the viewer has a sensitive personal condition.

## Create useful variants

Change the buying angle, proof emphasis or objection while preserving factual details and the intended test. Keep important meaning in the opening because placement text can truncate; inspect actual previews rather than relying on an assumed universal display limit.

## Existing media

Read any embedded text before writing the caption. Preserve acceptable owner-approved artwork. For newly generated text and visuals, ensure the asset and caption tell the same story and record exactly which claim the agent added.

Read the shared [operating knowledge](../../meta-ads/references/operating-knowledge.md) for source references and evidence limits. The current skill's output schema remains authoritative.

## Applied purchase decisions

Connect opening message, credible explanation, offer/objection and CTA to the selected buying question. Keep factual offer details stable when comparing message variants. Write exact primary_text/headline/description/cta keyed by ad name, and read the embedded image/video text before composing the caption.

A product benefit should retain the source qualification: do not turn helps improve appearance into a guaranteed treatment or timeline. Do not fabricate testimonials, scarcity or discounts. For a price objection, explain actual included value and terms rather than inventing a cheaper offer. Inspect placement truncation and destination consistency. A high CTR headline that promises the wrong experience is not a successful purchase strategy.

Read the [shared decision method](../../meta-ads/references/decision-method.md) for calculations, evidence grades, scenario diagnosis, authority and maintained source links. Preserve a dated observation versus hypothesis distinction in the handoff.
