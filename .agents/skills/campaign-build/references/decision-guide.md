# Save the approved design faithfully

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Before writing

Read the validated exact plan, account, budget impact, product destination, identities, audiences and current media revisions. Check the account for an existing matching managed object before a new create.

## Execution method

Prepare the exact proposal through the lifecycle and execute authorized work via the GitHub Meta gateway. The gateway journals intent before a mutation and records verified IDs after readback. The agent supplies plugin evidence and media; it does not need to export plugin credentials.

## Failure behavior

A network timeout can occur after Meta created an object. Inspect the saved journal and read Meta before retrying. Reconcile partial results under the original proposal instead of starting another campaign.

## Completion

Create campaign, ad sets and ads paused. Verify hierarchy, objective/event, budgets, targeting, creative and destination. Pass the exact receipt to Campaign Launch; report a paused build as a paused build.

Read the shared [operating knowledge](../../meta-ads/references/operating-knowledge.md) for source references and evidence limits. The current skill's output schema remains authoritative.

## Applied purchase decisions

Compile the validated typed plan and verify funding, identities, Purchase event, audience eligibility, destinations, media revisions and approvals. Build objects paused and read each back. An addition can use an existing active ad set, or create a new paused ad set under an existing campaign budget. Independently funded new ad sets require a verified allocation plan; do not create overlapping unapproved exposure.

Feed carousels preserve approved card order and use all selected image revisions. A catalogue plan must bind catalogue_id/product_set_id/retailer_ids to connected product/variant evidence and verify feed URLs, currency, availability and source linkage. Unsupported dynamic variations remain explicitly unavailable. Durable checkpoints and reconciliation handle partial writes; never regenerate names and duplicate objects to hide a timeout.

Read the [shared decision method](../../meta-ads/references/decision-method.md) for calculations, evidence grades, scenario diagnosis, authority and maintained source links. Preserve a dated observation versus hypothesis distinction in the handoff.
