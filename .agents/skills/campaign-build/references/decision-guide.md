# Save the approved design faithfully

This is the system's operating method. Account settings and current provider capabilities still require readback.

## Before writing

Read the validated exact plan, account, budget impact, product destination, identities, audiences and current media revisions. Check the account for an existing matching managed object before a new create.

## Execution method

Prepare the exact proposal through the lifecycle and execute authorized work via the GitHub Meta gateway. The gateway journals intent before a mutation and records verified IDs after readback. The agent supplies plugin evidence and media; it does not need to export plugin credentials.

## Failure behavior

A network timeout can occur after Meta created an object. Inspect the saved journal and read Meta before retrying. Reconcile partial results under the original proposal instead of starting another campaign.

## Completion

Create campaign, ad sets and ads paused. Verify hierarchy, objective/event, budgets, targeting, creative and destination. Pass the exact receipt to Campaign Launch; report a paused build as a paused build.
